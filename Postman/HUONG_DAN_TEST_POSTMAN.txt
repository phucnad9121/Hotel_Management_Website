BUOC 1.1: Start XAMPP
────────────────────────────────────────────────────────

BUOC 1.2: Kiem tra Database
────────────────────────────────────────────────────────
  1. Mo trinh duyet (Chrome/Edge)
  2. Truy cap: http://localhost/phpmyadmin
  3. Ben trai, click vao database "web_hotel_mngt"
  4. Kiem tra co cac bang nay:
     ✅ authentication_admin
     ✅ authentication_login
     ✅ hotels_guests
     ✅ hotelservice_services
     ✅ bookings_booking
     ✅ rooms_room
     ✅ rooms_roomtype

  5. Neu KHONG thay cac bang tren → DUNG O DAY, tao database truoc!

BUOC 1.3: Tao du lieu test (NEU CHUA CO)
────────────────────────────────────────────────────────
  1. Trong phpMyAdmin, click tab "SQL" (tren dinh)
  2. Paste TOAN BO code duoi day vao o nhap lieu:

     VALUES ('AD001', 'admin', '123456');

     VALUES
       ('DV001', 'Spa Massage', '60 minutes massage', 500000),
       ('DV002', 'Laundry', 'Same day laundry service', 100000);

     VALUES ('LP001', 'Standard', 500000);

     INSERT INTO rooms_room (MaPhong, SoPhong, MaLoaiPhong, KhaDung)
     VALUES ('P101', '101', 'LP001', 'Yes');

     INSERT INTO hotels_guests
       (MaKhachHang, HoKhachHang, TenKhachHang,
        SoDienThoaiKhachHang, MatKhau)
     VALUES
       ('KH001', 'Nguyen', 'Van A', '0901234567', '123456');
     ──────────────────────────────────────────────────

  3. Click nut "Go" (goc phai duoi)
  4. Neu hien "Successfully" hoac khong bao loi → OK ✅
  5. Neu bao loi "already exists" → Du lieu da co → BO QUA buoc nay

================================================================================
PHAN 5: SUA LOI NHANH
================================================================================

❌ LOI: Ra HTML thay vi JSON (O BAT KY TEST NAO)
   → Sai base_url HOAC .htaccess khong hoat dong
   → KIEM TRA:
     1. Click Environment ✏️ (goc phai tren)
     2. Xem variable "base_url"
     3. PHAI CO DU: http://localhost/Hotel_Management_Website/api.php/api
     4. Neu thieu "api.php" → Them vao → Save
   → Neu VAN sai → Bao toi: Status + Response

❌ LOI: 401 "Invalid username or password" (Test 2)
   → Chua co admin trong DB
   → Vao phpMyAdmin → Tab SQL → Chay:
      INSERT INTO authentication_admin
        (MaDangNhap, TenDangNhap, MatKhau)
      VALUES ('AD001', 'admin', '123456');

❌ LOI: 401 "Token required" hoac "Unauthorized"
   → Token khong hop le
   → Quay lai Test 2, Login lai

❌ LOI: 500 "Server error"
   → Xem phan response co chi tiet loi khong
   → Copy noi dung loi gui cho toi

❌ LOI: 404 "Route not found"
   → URL sai
   → Kiem tra base_url co dung khong
